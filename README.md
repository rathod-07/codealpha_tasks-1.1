# 🌐 Language Translation Tool (CodeAlpha_Task-1)

A Python-based Language Translation Tool that translates text from one language to another using the Google Translator service through the "deep-translator" library.

🚀 Features

- Supports 7 Languages.
- English to Marathi Translation.
- Marathi to English Translation.
- Hindi and other language translations.
- Simple and user-friendly interface.
- Input validation.
- Error handling.
- Translate multiple texts without restarting the program.

🛠️ Technologies Used

- Python
- Deep Translator
- Google Translator Service

🌍 Supported Languages

1. English
2. Marathi
3. Hindi
4. French
5. German
6. Spanish
7. Japanese

📥 Installation

Step 1: Clone the Repository

git clone https://github.com/rathod-07/codealpha_tasks-1.1.git

Step 2: Install Required Library

pip install deep-translator

Step 3: Run the Project

python language_translator.py
